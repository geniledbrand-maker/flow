# Russian Fishing 4 — Roadmap для новичка 🎣

Одностраничный локальный сайт-роадмап: с чего начать в Russian Fishing 4, как
не слить деньги и куда расти — от Комариного озера до трофеев.

## Как открыть

Просто **открой `index.html` двойным кликом** в любом браузере. Всё внутри
одного файла (HTML + CSS + JS), без сервера, сборки и интернета.

## Что внутри

- Пошаговый roadmap по этапам (уровни 1 → эндгейм)
- Стартовые снасти и наживки
- Какую рыбу ловить первой
- Как зарабатывать серебро (заказы кафе, ночной фарм окуня, лещ на фидер)
- Прокачка уровня и навыков
- Таблица водоёмов с уровнями открытия
- Частые ошибки новичков
- Интерактивный чеклист новичка (прогресс сохраняется в браузере)
- Ссылки на актуальные живые ресурсы (rf4.info, rf4-stat, rf4.cafe, wiki.gg)

## Важно

Уровни открытия водоёмов и детали клёва — ориентировочные и могут меняться с
патчами. Самые свежие данные по точкам, наживкам и ценам — на живых
сайтах-картах, ссылки на них есть в самом роадмапе (раздел «Ресурсы»).
